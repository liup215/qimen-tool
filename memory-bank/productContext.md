# 产品上下文

## 为什么做这个项目
奇门遁甲是中国古代三大式（太乙、奇门、六壬）之一，排盘过程复杂，涉及节气、干支、九宫、门星神等多层信息。传统手工排盘耗时且容易出错，现有软件多为付费或界面老旧。一个开源、可解释、可学习的自动化工具能降低学习门槛，并提供可验证的排盘逻辑。

## 解决的问题
1. **排盘繁琐**：手工计算节气、局数、旬首、空亡、值符值使容易出错。
2. **解释不透明**：很多软件只给结果，不给规则来源。
3. **学习困难**：缺乏可视化的盘面和规则说明对照。

## 用户体验目标
- 通过命令行输入时间，毫秒级生成标准奇门盘。
- 默认输出结构化 JSON，方便 agent/程序解析。
- 支持 `--format text/markdown` 输出人类可读的九宫格盘面与解释。
- 解释模块明确标注规则来源（经典格局、五行生克、门星神组合）。
- 支持保存案例为 JSON 文件。

## 关键假设
- 用户至少具备基础易学知识（天干地支、八卦九宫）。
- 工具定位为学习和参考，不替代专业判断。
