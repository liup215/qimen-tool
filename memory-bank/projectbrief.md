# 奇门遁甲自动化工具 —— 项目简史

## 项目目标
构建一个可以自动化进行奇门遁甲排盘与解释的数字化学习/应用工具。

## 核心需求
1. **自动排盘**：给定阳历/阴历时间，自动计算并生成奇门遁甲盘（时家奇门优先）。
2. **盘面展示**：以直观方式展示天盘、地盘、八门、九星、八神、空亡、马星、旬首、值符、值使等信息。
3. **智能解释**：基于经典奇门遁甲规则，对宫位、用神、格局、吉凶等进行解读。
4. **学习辅助**：提供规则说明、用神查询、格局库、案例库，帮助用户学习。

## 项目范围（初版）
- 优先实现最常见的 **时家奇门（转盘法）** 排盘。
- 支持阳遁九局、阴遁九局，共 18 局。
- 支持基本用神设置（年命、日干、时干、值符、值使等）。
- 提供基础解释模块：宫位五行生克、吉格凶格、门星神组合含义。

## 非目标（初版不做）
- 复杂的风水实地堪舆计算。
- 多种流派的冲突规则统一（如转盘/飞盘、拆补/置闰争议）。
- 自动给出确定性的人生决策建议。

## 目标用户
- 奇门遁甲学习者
- 研究者、术数爱好者
- 需要快速起盘参考的从业人员
